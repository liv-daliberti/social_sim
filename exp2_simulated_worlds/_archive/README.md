# Retired simulated-world study

`biased_news_legacy/` contains the superseded evaluation, recovery-curve,
scheduler, configuration, and output paths from the early biased-news study.
The current paper retains only the coin probe under `../biased_news/eval/`, while
the deployed historical-results viewer retains its temporal-DAG engine and batch
data. The world generator still used by Experiment 3 was moved to
`../../exp3_training_transfer/biased_news/worlds.py`.

Nothing under this archive is imported, tested, deployed, or packaged.
