## Interpretation

Within-family scaling appears in both Qwen3 and Llama 3.1. Qwen3 4B/8B/14B symbol-minus-no-context Δρ values are 0.095 [-0.060, 0.230], 0.023 [-0.128, 0.171], 0.398 [0.253, 0.541]; Llama 3.1 8B/70B values are 0.045 [-0.123, 0.250], 0.424 [0.314, 0.543]. The larger checkpoint recovers the episode-local mapping in both families.

The boundary is family-specific rather than a universal parameter cutoff: Qwen2.5 7B/32B/72B Δρ values are 0.264 [0.112, 0.406], 0.372 [0.226, 0.502], 0.381 [0.250, 0.508]. Their corresponding ΔMAE values are 0.338 [0.027, 0.682], 0.529 [0.169, 0.924], 0.924 [0.582, 1.310], so mapping recovery does not by itself guarantee calibrated numerical use.

At frontier scale, both capabilities coincide. Claude Opus 4.8, Claude Opus 5, and GPT-5.6 Sol have Δρ values 0.623 [0.492, 0.744], 0.591 [0.485, 0.697], 0.696 [0.597, 0.807] and ΔMAE values -0.584 [-0.858, -0.314], -0.603 [-0.869, -0.336], -0.774 [-1.011, -0.533]. DeepSeek V4 Pro has Δρ 0.436 [0.323, 0.558] and ΔMAE 0.107 [-0.222, 0.452]; Kimi K3 has Δρ 0.633 [0.520, 0.742] and ΔMAE -0.497 [-0.765, -0.211].

For the large Qwen2.5 models and Llama 3.1-70B, the zero-shot discrimination advantage fades as City C observations accumulate. The induced label is most useful before direct target evidence is available.

Reading guide: positive Δρ/Δaccuracy indicates better arbitrary-label discrimination; negative ΔMAE indicates better numerical forecasts. These properties can move in different directions.
