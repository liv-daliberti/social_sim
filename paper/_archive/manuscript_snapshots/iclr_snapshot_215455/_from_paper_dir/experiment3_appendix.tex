\subsection{Experiment 3: Coin City Domain and Structural Transfer}
\label{app:exp3-coin-structural}

\subsubsection{Data-generating processes}

Training uses only Structure~A, the direct relationship from Experiment~2. On
the displayed scale of domain $d$,
\begin{equation}
  y_{t+1}=b_d+g_jx_t+\epsilon_t,\qquad
  \epsilon_t\sim\mathcal N(0,\sigma_d^2).
  \label{eq:exp3-coin-a}
\end{equation}
A pulse acts in the next period and has no residual effect under zero subsequent
input. The unseen evaluation mechanism, Structure~B, is
\begin{align}
  m_{t+1}&=\rho m_t+g_jx_t,\\
  y_{t+1}-b_d&=\phi(y_t-b_d)+\lambda m_{t+1}+\epsilon_t.
  \label{eq:exp3-coin-b}
\end{align}
It introduces a persistent mediator and outcome carry-over, so a single pulse has
both immediate and delayed effects. Model prompts disclose neither equation,
parameter values, internal variable, nor structure label.

Coin City uses $b=50$, range $[0,100]$, driver pool
$\{-12,-8,-4,0,4,8,12\}$, and $\sigma=1.6$. Held-out Coin Harbor uses
$b=180$, range $[40,320]$, driver pool
$\{-24,-16,-8,0,8,16,24\}$, and $\sigma=4.5$, together with new terminology,
units, and qualitative descriptions. Evaluation gains follow
$g\sim\mathrm{Uniform}(.22,.92)$. Structure~B independently samples
$\rho\sim\mathrm{Uniform}(.48,.74)$,
$\phi\sim\mathrm{Uniform}(.18,.42)$, and
$\lambda\sim\mathrm{Uniform}(.68,.94)$. A reference and its matched target share
these parameters but have independent inputs and noise.

\subsubsection{Training episodes and matched control}

Each training prompt contains two 14-case Coin City reference systems, both
governed by Equation~\ref{eq:exp3-coin-a}. One draws
$g\in[.18,.46]$ and the other $g\in[.68,.98]$; their order is randomized.
The target shares exactly one reference gain, selected in balanced fashion, and
shows $k\in\{0,2,4,8\}$ independently generated cases. Its national/local
background description identifies the matching weak or strong response as in
Experiment~2. There are 1,200 rows at each $k$, or 4,800 per training run.

The causal and population-prior datasets have byte-identical prompts. Causal
reward uses the target's noise-free forecasts. For the control, targets are
deranged within each $k$ stratum with a fixed permutation: no row keeps its own
target, while the complete multiset of target vectors is exactly preserved.
Consequently the control can learn the output format and population distribution
but cannot improve reward by using that row's references or target history.
The Qwen3-4B structureless diagnostic additionally scrambles displayed drivers
and rewards a flat intervention response; it is not a confirmatory comparator.

\subsubsection{Evaluation interface and qualitative hint}

Every evaluation prompt contains a complete 14-period Structure~A reference, a
complete 14-period Structure~B reference, and a target governed by one of them.
For Coin City the two reference descriptions are:
\begin{quote}\small
Residents receive campaign developments through synchronized citywide alerts.
Reactions occur mostly during the same week as the news.

Campaign developments usually spread through neighborhood conversations and
local organizations. Reactions may build gradually and persist after the
original news has faded.
\end{quote}
Coin Harbor uses the matched fleetwide-radio versus dockside-network descriptions.
The target receives the correct description, no description, or the other
pathway's description. The three prompt variants reuse the exact reference and
target trajectories, scenario grid, and gold forecasts; the freeze records a
common numeric hash for every cue triplet.

Each task requests ten counterfactuals: shocks
$\{-2u_d,-u_d,0,u_d,2u_d\}$ at horizons one and three, with $u_d=6$ in Coin City
and $u_d=12$ in Coin Harbor. The shock occurs in the next period and all later
inputs are zero. The response vector consists of the eight nonzero-shock minus
zero-shock contrasts. The full endpoint contains
\[
2\ {\rm domains}\times2\ {\rm structures}\times3\ {\rm hints}\times
4\ k{\rm\ values}\times30\ {\rm episodes}=1,440
\]
paired prompts. Training and evaluation seed bands begin at 81,000,000 and
91,000,000, respectively.

The renderer realizes the variants as follows. Training always includes the
correct strong/weak background and uses the same input string for causal and
population-prior training; only the hidden reward target differs. At evaluation,
\texttt{correct} inserts the target pathway's description, \texttt{none} omits
the background line entirely, and \texttt{misleading} inserts the other
pathway's description. Every cue triplet otherwise has identical tables,
interventions, and targets. If $k=0$, the target block contains the exact
sentence \emph{No target-system observations are available yet.}; otherwise it
contains the same table format as the references with the first $k$ rows. The
Qwen3-4B \texttt{structureless} diagnostic retains this shell but swaps every
displayed $-12.0\leftrightarrow12.0$ and $-8.0\leftrightarrow8.0$ token through
a collision-safe substitution. Untrained bases receive the same held-out
prompts as trained models. Thus cue, reward-arm, structureless, and base
comparisons do not introduce an unreported instruction change.

\subsubsection{Estimands, roster, and validation criteria}

The confirmatory grid is three models (Qwen3-4B, Qwen3-8B, and
Llama-3.1-8B), two arms, and three training seeds, for 18 runs. Three
Qwen3-4B structureless runs and three untrained endpoints are diagnostic.
The primary estimand is population-prior minus causal response MAE on
Structure~B in Coin Harbor with the correct hint, averaging the four $k$ values
equally. Positive values favor causal training. Prespecified secondary contrasts
apply the same estimator to Structure~A/Coin Harbor (domain transfer),
Structure~B/Coin City (structural transfer), and the in-distribution cell.
Paired absent-minus-correct and misleading-minus-correct contrasts measure hint
use. Their paired $k=8$ minus $k=0$ difference tests whether observations override
a misleading prior; negative values indicate a shrinking misleading-hint penalty.

Greedy output is retained for continuity, and every checkpoint adds five draws at
temperature $.7$. Draws are averaged within episode before inference. The
hierarchical bootstrap resamples the three training seeds at the top level and
paired episodes within each selected seed. Parse failures receive the full
observable-range error penalty rather than being discarded.

The generated freeze passes 17 fail-closed checks: exact row counts and factorial
balance; byte-identical causal/prior prompts and held-out datasets; exact
within-$k$ target marginals with no fixed reward links; absence of Structure~B
from training prompts and metadata; cue-triplet numeric identity; train/evaluation
identifier disjointness; hidden-equation leak scans; strict gold round trips; and
oracle separation from the blind pathway mixture. Mean A--B response separation
is 2.65 points in Coin City and 4.80 in Coin Harbor. Across all three tokenizers,
the longest prompt is 1,071 tokens against the registered 2,304-token limit.

The analysis plan assigns population-prior-minus-causal intervals to all four
transfer cells, paired intervals to both cue penalties at every $k$, and the paired
$k=8$ minus $k=0$ change in misleading-minus-correct error to evidence override.
The protocol archive records versioned input, analysis, and output hashes. Full
optimization and compute parameters are in
Section~\ref{app:exp3-complete-training-setup}.

\subsection{Domain-Transfer Precursor: Coin-\texorpdfstring{$*$}{*}}
\label{app:exp3-domains}

This diagnostic asks whether training on one to three
surface domains improves forecasting on two unseen domains when the causal
structure and total number of training rows are held fixed. This earlier
Coin-$*$ precursor is distinct from the main Coin City/Coin Harbor factorial;
Figure~\ref{fig:exp3d-domains} shows its full five-domain roster.

\input{fig_exp3d_domains}

\subsubsection{Design and anti-shortcut controls}

Every domain in this precursor instantiates the same fixed structure: a driver
$x_t$ moves a hidden state that retains $0.9$ of its previous deviation from
baseline, and the observable reports that state with measurement noise. Domain
names, terminology, units, and numerical parameterization differ, while the causal
topology is preserved. Writing $y^{\mathrm{c}}$ and $u^{\mathrm{c}}$ for the
canonical observable and driver, domain $d$ displays
\begin{equation}
  y_d = o_d + s_d\,(y^{\mathrm{c}} - 50), \qquad x_d = i_d\,u^{\mathrm{c}},
  \qquad g_d = (s_d / i_d)\, g^{\mathrm{c}},
  \label{eq:exp3d-skin}
\end{equation}
with per-domain offset $o_d$, observable scale $s_d$, and driver scale $i_d$. The
map is affine and invertible, so reward targets and the slope target transform
identically and the Kalman oracle remains optimal in canonical space. Observation
noise is set per domain on the underlying structure rather than inherited from
$s_d$, so scale and noise are not confounded. Table~\ref{tab:exp3d-domains} gives
the resulting displayed parameters.

Two consequences matter for interpretation. The implied sensitivity $g_d$ differs
across domains even at the same canonical draw, so a policy that memorizes a
numeric regime in training cannot apply it to a held-out domain. And because each
domain draws its episodes from a disjoint seed block, no canonical episode is ever
re-skinned into two domains; CoinFishing is not CoinCity's numbers multiplied by
four.

Rows carry their own reward tolerances, scaled by $s_d$ for the level term and by
$s_d/i_d$ for the slope term, together with the domain's observable range. Without
domain scaling, a fixed tolerance in displayed units would make CoinFishing
roughly four times harder than CoinCity at equal relative accuracy. Forecasts outside $[0,100]$
would also be clipped, including every CoinFishing answer above 100 crates, which
would destroy the measured slope.

\subsubsection{Registered protocol and completion}

The preflight is fail-closed and gates submission: row-matching across arms,
nesting of the training sets, absence of any held-out domain from training,
train/evaluation seed disjointness, targets inside the declared range, skin-scaled
tolerances, byte-identical held-out splits, and an oracle-versus-constant reward
margin on each held-out domain. It passes on the submitted datasets. All four arms
carry exactly 4{,}800 training rows in equal per-domain shares; on training rows
the correlation between the true displayed sensitivity and the slope target is
$1.00$ for $D_1$--$D_3$ and undefined for the structureless control, whose slope
targets are identically zero; and on the held-out domains an oracle that knows the
hidden sensitivity outscores a constant ``ignore the driver'' policy by $0.548$
reward on CoinBasketball and $0.560$ on CoinClinic. Its manifest is
\texttt{domain\_family/protocol/exp3d\_manifest.json}.

\paragraph{Training and read-out.}
Every arm fine-tunes \texttt{Qwen3-4B-Instruct-2507} with rank-32,
$\alpha{=}64$ LoRA adapters and Dr.~GRPO for 300 rollout-and-update rounds at seeds 42, 43, and 44.
Each update samples 16 prompts with eight rollouts per prompt at temperature 1.3;
the learning rate is $10^{-6}$ and greedy held-out evaluation runs every 25
updates. Reward weights level and slope accuracy equally, with tolerances scaled
by each domain's display skin; an invalid response receives zero reward. The
full registered grid completed at all three seeds. The main-text endpoint table
pools the three validated seeds and evaluates the deterministic step-zero base
once. The registered launcher and scorer are \texttt{launch\_domains.py} and
\texttt{transfer\_report\_domains.py}.

\subsection{Secondary Diagnostic: Causal-Structure Transfer}
\label{app:exp3-structures}

This completed arm varies the disclosed causal graph while retaining the election
setting. It complements the primary domain test by asking whether training can
use an unseen described graph; because the graph is supplied in the prompt, it is
not a test of discovering causal structure from observations alone.
\subsubsection{World Family}
\label{app:exp3-family}

Each world is a linear-Gaussian state-space model with one hidden scalar, the per-episode gain
$g\sim\mathrm{Uniform}(0.1,1.0)$, which occupies a single designated slot of $B$ (an input gain) or of
$A$ (a persistence):
\begin{align}
s_t &= \text{base} + A\,(s_{t-1}-\text{base}) + B(g)\,u_t + w_t, & w_t&\sim\mathcal N(0,\sigma_s^2 I),\\
y_t &= C\,s_t + v_t, & v_t&\sim\mathcal N(0,\sigma_y^2 I),
\end{align}
with $\text{base}=50$, $\sigma_s=1$, $\sigma_y=2$, a weekly driver $|u_t|\sim\mathrm{Uniform}\{3,\dots,12\}$
with random sign, horizon $T=10$, and $y_t$ clipped to $[0,100]$ and rounded. Experiment~2's biased-news
world is exactly the \texttt{direct} structure ($d{=}m{=}p{=}1$, $A{=}[\phi]$, $B{=}[g]$, $C{=}[1]$,
$\phi{=}0.9$). The catalog holds $12$ single-poll structures, split $8$ training / $4$ held-out
(Table~\ref{tab:exp3-worlds}).

\paragraph{Design gates.} Every world is asserted at import: the spectral radius
of $A$ must be below one at both ends of the gain range, the resting observable
$C\cdot\text{base}$ must lie in $[25,75]$, and clipping must remain below $0.4\%$.
These gates keep all reported processes stable, centered away from the bounds,
and identifiable under the probe below.

Distinctness is checked within each observational interface by applying
structure $A$'s Kalman oracle to structure $B$'s data. Each world's native oracle
is best, by $21\%$ for the deepest chain to $463\%$ for the most separated pair;
no held-out world is an observational relabeling of a training world.

\subsubsection{Instrument: Probing at the First-Response Horizon}
\label{app:exp3-probe}

Experiment~2 reads recovery by asking for the poll under each of four shocks
$\{-10,-5,+5,+10\}$ and taking the slope of the answers. Applied at a fixed one-week horizon this is
\emph{degenerate} in every delayed world: $y_{k+1}$ does not depend on $u_{k+1}$, so all four targets
coincide, the true slope is $0$, and a constant reply is optimal. Six of the twelve worlds are blind this
way (Fig.~\ref{fig:exp3-probe}a). We therefore probe each world at its own $h^\star$. Under a single
pulse $u$ at week $k{+}1$ and no news thereafter,
\begin{equation}
\mathbb E[y_{k+h}] \;=\; C\Big(\text{base} + A^{h}(s_k-\text{base}) + A^{h-1} B\,u\Big),
\end{equation}
so the slope of the four answers against the shock magnitude estimates $\gamma^\star=(CA^{h^\star-1}B)$,
which equals $g$ exactly in the direct world and is an affine image of it elsewhere. The prompt states
the horizon explicitly (``news in week $k{+}1$, none in weeks $k{+}2$--$k{+}h^\star$; predict the poll in
week $k{+}h^\star$''), and asks for all four scenarios in one reply, which is what makes the slope
readable from a single completion.

\paragraph{Identifiability guard.}  Even at $h^\star$, a short prefix may leave $g$ unidentified: the
filter has not seen enough polls. We score only (structure, prefix) cells in which knowing $g$
improves oracle performance over the prior-blind filter by at least $0.1$ poll points.
This retains every prefix $k\in\{1,2,3,5,7,9\}$ for \texttt{direct} and \texttt{two\_news\_feedback}, and
$k\geq5$ for \texttt{mediators} and \texttt{chain4}.

\subsubsection{Reward}
\label{app:exp3-reward}

The agent never sees $g$; it emits only poll forecasts. Forecast accuracy alone is
improvable without inference because a policy can answer at the prior-mean gain.
The registered reward therefore scores response as well as level from the four
jointly elicited forecasts $\hat p_i$ (Eq.~\eqref{eq:exp3-reward}):
\begin{equation}
r=(1-w)\cdot\tfrac14\sum_{i}\max\!\big(0,1-|\hat p_i-\mu_i|/S\big)\;+\;w\cdot\max\!\big(0,1-|\mathrm{slope}(\hat p)-\gamma^\star|/S_g\big),
\label{eq:exp3-reward}
\end{equation}
with $w{=}0.5$, $S{=}15$ poll points, $S_g{=}0.5$, and $\mu_i$ the noise-free target under shock $i$. The
slope term is per-episode: it is earned only by reading \emph{this} city's history. A reply missing any
of the four scenarios, or truncated at the token budget, earns $r{=}0$; partial credit is refused because
a missing scenario corrupts the slope. Under $h^\star$ the constant policy's take falls from $70\%$ to
$46\%$ of the oracle's, and it falls in \emph{every} world rather than only the immediate ones
(Fig.~\ref{fig:exp3-probe}b).

\subsubsection{Structureless Control}
\label{app:exp3-control}

Training against this reward can still lower held-out error for reasons unrelated to the
driver--outcome relationship: the model may learn the JSON format, learn to track the poll's level, or learn to stop over-reacting to news.
The control arm removes the driver--outcome relationship. Its training rows use the same
worlds, the same prompts, and the same episodes, but (i) the \emph{displayed} news is resampled
independently of the polls, so news and poll share zero mutual information; (ii) every scenario's target
is the expected poll under \emph{zero} input, so all four coincide; and (iii) the slope target is $0$. A
control-trained model can learn format, level-tracking, and news suppression. Its
training data contain no news$\to$poll relation.

Both reported arms are evaluated on the same real held-out worlds. Family and
structureless held-out files are byte-identical, and the preflight aborts on any
target, seed, structure, horizon, or prompt drift. Empirically the manipulation
does what it claims: on family training rows the displayed news correlates
$+0.385$ with the observed poll change, and on structureless rows $+0.017$.

\paragraph{Control interpretation.} The structureless arm sees incoherent
news--poll pairs, which are off-distribution at test time, and a news-ignoring
constant already earns $86\%$ of its achievable training reward versus $46\%$
on family data. Both asymmetries favor the family arm, so failures to separate
from the control remain informative.

The exception is \texttt{chain4}: its small true response range
$[0.022,0.216]$ lies close to the control's zero-slope target. The control is
therefore accidentally trained toward the average answer, and its lower raw
$\varepsilon$ on this world is not interpreted; its near-zero $\rho$ remains a
valid indicator that it does not order cities.

Even where valid, family minus structureless does not isolate per-city inference:
a family win can arise from applying the disclosed graph at a population-average
gain. We scope this contrast to whether training used forecast structure at all.

\subsubsection{Data}
\label{app:exp3-data}

Training rows are drawn only from the $8$ training structures ($600$ episodes each, $4800$ rows); each row
is one (structure, episode, prefix $k\in[1,9]$) with a shock quadruple sampled two-negative/two-positive
from a wider pool than the evaluation shocks, so the model learns the response across a range rather than
memorizing four points. The held-out split is drawn only from the $4$ held-out structures ($60$ cities
each $\times$ six prefixes $k\in\{1,2,3,5,7,9\}$, $1440$ rows) at the canonical four shocks. Train and
held-out episodes come from disjoint seed bands ($10^5$-based vs.\ $9\!\times\!10^{7}$-based), so no city
is shared; and because the two splits contain \emph{disjoint structures}, the held-out set tests transfer
across structures as well as cities.

\paragraph{Information supplied in the prompt.} As in Experiment~2's parity prompt, the generative
structure is \emph{disclosed} and only $g$ is hidden. A verbalizer describes the
number of latent opinions, their carry-over fractions and couplings, the drivers,
the poll readout, and the noise scales. The sole hidden slot is marked as ``an
UNKNOWN amount $g$ \dots\ inferring it is your job''. This arm tests whether the
model can use a disclosed but unseen state-space structure and estimate its free
parameter. It does not test graph induction. The structure-agnostic references
receive less information than the model and are conservative comparators.

\paragraph{Output contract.} The model returns exactly one JSON object carrying
\texttt{poll\_A}\dots\texttt{poll\_D}, with reasoning capped at two short
sentences. Greedy parse coverage is $100\%$ at every held-out checkpoint,
including step zero, so before/after differences are not formatting gains.

\subsubsection{Training Setup}
\label{app:exp3-train}

We fine-tune \texttt{Qwen3-4B-Instruct-2507} with Dr.\ GRPO\footnote{The bias-corrected GRPO of Liu et
al., \emph{Understanding R1-Zero-Like Training: A Critical Perspective} (2025), which removes the
response-length and reward-standard-deviation biases of the group-relative advantage.} as implemented in
the OAT framework\footnote{\emph{OAT: A research-friendly framework for LLM online alignment},
\url{https://github.com/sail-sg/oat}.}, a single-GPU actor--learner setup collocating a vLLM sampler with
the learner. Optimization is over LoRA adapters only, on top of the frozen base; the objective is the
unbiased Dr.\ GRPO variant (no length normalization, no standard-deviation division in the group-relative
advantage) with KL penalty $\beta{=}0$. Full hyperparameters are in Table~\ref{tab:exp3-hparams}.

Temperature $1.3$ and reward scale $15$ preserve within-group reward variation;
all reported runs use this registered configuration.

\subsubsection{Read-out and References}
\label{app:exp3-readout}

Each held-out record is one (structure, city, prefix) asked under four shocks jointly, so one completion
yields the forecast error $\pi=\overline{|\hat p_i-\mu_i|}$ and the implied response
$\hat\gamma=\mathrm{slope}_i(\text{shock}_i,\hat p_i)$. Where recovery is defined we report
$\varepsilon=\overline{|\hat\gamma-\gamma^\star|}$ per city and $\rho$, the Spearman correlation of
$\hat\gamma$ with $g$ across cities. A forecaster whose $\hat\gamma$ never varies is \emph{blind}, not
undefined: it orders no cities, so $\rho=0$ (the Experiment-2 convention for always-prior).

Six references are computed on the \emph{identical} episodes at the same $h^\star$
(Table~\ref{tab:exp3-refs}). The read-out refuses to score a dump whose references were written under a
different probe horizon, so results from the pre-$h^\star$ generation cannot be silently mixed with
current ones.

\subsection{Experiment 4: Historical Polymarket Pastcasting}
\label{app:exp3b-protocol}

This study asks whether outcome-based training transfers to events and normalized
question families unseen during training, using a point-in-time cutoff and sealed
test.

\subsubsection{Frozen sample and leakage gates}

\paragraph{Frozen source and sample.}
The source export has 1,788,703 rows and SHA-256
\texttt{5697f767\ldots f638e7d} (the full digest is stored in the manifest).
The builder scans the entire file and fails on checksum drift. The frozen calendar
splits contain 1,736 train, 512 development, and 1,024 test markets, with YES rates
.311, .275, and .301. Train contains 991 distinct events and 1,456 normalized
question templates; development contains 292 and 453; test contains 493 and 866.
The selected archive rows have no official series identifiers, so event and
template components supply the operative family groups.

\paragraph{Eligibility and point-in-time censoring.}
We admit literal Yes/No markets resolved by an extreme final token price. A
boundary-aware domain rule selects political, governmental, macroeconomic, and
geopolitical questions while explicitly rejecting culture, awards, sports,
esports, and crypto categories. This rule is fixed before model training. One task
is built 30 days before the earliest archived terminal timestamp. At least four
distinct UTC dates must have genuine pre-cutoff YES candles, the latest candle must
be no more than seven days stale, and its price must remain in $[.02,.98]$. We keep
at most the latest 14 dates. Empty, carry-forward, and post-cutoff candles are
rejected. The prompt omits the outcome, final prices and volume, market status,
realized terminal time, and the tags used for domain selection.

The archive records timestamped price history but not revisions to static question
or resolution-rules text. We therefore treat those strings as time-invariant. This
is a residual point-in-time limitation: the audit can prove that no timestamped or
outcome field crosses the cutoff, but cannot prove that an archived rule was never
edited later.

\paragraph{Family-disjoint temporal split.}
Before applying sample caps, every development row sharing an event, available
series, or normalized template with train is removed; the same rule removes test
rows matching train or development. Numeric values and month names are normalized
in template keys. The final intersection is zero for each pair of splits. Sampling
within a split is a stable hash of task identifier and protocol version, so row
order in the export cannot change membership.

\subsubsection{Registered training and sealed evaluation}

\paragraph{Matched update budget.}
The target domain yields 1,736 unique train markets rather than 4,800. We preserve
the precommitted 300-round comparison with Experiment~3A using a deterministic,
balanced schedule of 4,800 presentations: every market appears twice and 1,328
appear a third time. Schedule order and task files are hash-locked. With batch size
16 this gives exactly 300 rollout-and-update rounds (2,400 AdamW steps). This distinction between unique markets and
presentations is retained in every manifest and table. The longest wrapped prompt
is 1,012 Qwen tokens against the 1,792-token training limit, so OAT's prompt filter
drops no task.

\subsection{Scope and Limitations}
\label{app:exp3-limitations}

The completed endpoint claims cover Qwen3-4B in the broad-composition study,
Coin City under both registered decoding regimes, and historical-market training.
The larger-model protocols specify scale and architecture comparisons; they do
not broaden the current empirical claims.

\textbf{Coin City confirmation scope.} The A-to-B design crosses an unseen
persistent-mediator mechanism with a held-out domain and withholds equations and
graph labels. At round 300, causal training lowers joint-transfer MAE relative to
the population-prior control under both decoding regimes, but the mechanism-shape
diagnostic remains poor. The qualitative hints can be correct, absent, or
misleading, but
they come from a fixed three-level intervention and the unseen family contains one
topology. The result therefore concerns this A-to-B contrast, not unrestricted
structure discovery or calibration to arbitrary natural cues.

\textbf{Coin-$*$ domain scope.} The five domains are affine display skins over a
fixed driver--state--observable graph. They vary names, units, scale, noise, and
sensitivity range, but not causal topology or genre. The held-out ranges also lie
inside the training ranges' convex hull. This is a controlled interpolation test,
not evidence of transfer to arbitrary natural domains or unseen mechanisms.

\textbf{Historical archive scope.} Timestamped prices are censored completely,
but the archive lacks edit histories for static question and resolution-rule
text; current tags select the target domain but never enter prompts. The design
uses one 30-day cutoff and price-extreme binary resolutions, so it need not extend
to other horizons, unresolved markets, or qualitatively adjudicated settlements.
The 300-round schedule repeats the 1,736 unique training markets in a balanced
way, increasing reuse; the family-disjoint sealed test, not training fit, carries
the generalization claim. The resulting gain shows predictive reuse across held-out event families but does
not show that the learned procedure recovers an explicit event model or causal
graph.

\textbf{Evidence-updating scope.} The secondary analysis fixes one Qwen~2.5-7B
initial structured forecast per market and reuses the synthetic Experiment~1
packets. This isolates conditional revision under controlled evidence;
it does not test whether training improves initial event-model construction,
retrieval, or updating to naturally occurring information.

\textbf{Causal-structure diagnostic.} The prompt supplies the graph and hides only
one scalar, so this arm tests use of a disclosed but unseen state-space
structure, not graph induction.
Moreover, \texttt{chain4}'s $h^\star{=}4$ response is only $0.02$--$0.22$ against
poll noise $\sigma_y{=}2$, making it a low-power endpoint. The single global slope
tolerance is not adjusted to each world's response range, and the forecast-based
reward optimizes response recovery only indirectly rather than directly scoring
the hidden parameter.

\textbf{Model and optimization scale.} The reported endpoint results use
Qwen3-4B, 300 Dr.\ GRPO rollout-and-update rounds, and three seeds per arm. The
additional protocols define a Qwen checkpoint/scale contrast and an approximately
parameter-matched Qwen/Llama contrast. The legacy open-weight roster used an
earlier one-step probe and structure family, so its endpoints are incompatible
with $h^\star$ and are not pooled with the reported factorial.
